# ตรวจสอบ Supabase ก่อนซ่อมระบบออนไลน์

1. เปิดโปรเจกต์ **Marslocal** ใน Supabase
2. เปิด **SQL Editor** → New query
3. เปิดไฟล์ [online_world_audit.sql](./online_world_audit.sql) จาก GitHub แล้วคัดลอก SQL ทั้งหมดไปวาง
4. กด **Run** แล้วส่งภาพหรือคัดลอกผลลัพธ์ตารางกลับมาในแชต

ไฟล์นี้เป็นการตรวจสอบแบบอ่านอย่างเดียว (read-only) ไม่สร้าง/แก้ไข/ลบข้อมูล ไม่แตะยอด MLC ไม่เปลี่ยนราคา THB และไม่เปลี่ยนสิทธิ์สมาชิก

## เหตุผลที่ต้องตรวจสอบก่อน

ในโฟลเดอร์ migrations มีไฟล์ประวัติหลายชุดที่ใช้เลขลำดับซ้ำกัน และมีไฟล์เก่าที่เปลี่ยนชื่อหน่วย MLC → ETH → USD → THB ขณะที่ระบบปัจจุบันต้องแยก **MLC** ออกจาก **THB** ดังนั้นห้ามนำไฟล์ทั้งหมดมารันรวดเดียวโดยไม่ตรวจสอบฐานข้อมูลก่อน

ผลตรวจจะบอกว่าส่วนใดพร้อม (OK) ส่วนใดขาด (MISSING) และ Realtime ส่วนใดยังไม่เปิด (NOT_ENABLED) จากนั้นจึงจัดทำ SQL ซ่อมเฉพาะจุดที่จำเป็น โดยไม่ทับข้อมูลเดิม

> MLC เป็นหน่วยจำลองภายในแอป ไม่ใช่เงินจริงหรือคริปโทเคอร์เรนซี ส่วน THB เป็นมูลค่าอ้างอิง/ช่องทางชำระเงินจริงที่ต้องตั้งค่าผู้ให้บริการแยกต่างหาก
