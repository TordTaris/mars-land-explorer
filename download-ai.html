How to Use

  • Select the Download HTML button
  • Open the file with Chrome or another supported browser
  • Open the AI page and select “Download / Load Model” to download the model for the first time
  • A WebGPU-compatible device and sufficient free storage are required
  • Alternatively, select Cloud AI and sign in to LOCAL MARS

Requirements: The downloaded app is a web client. It requires an internet connection, a LOCAL MARS account, and the configured Supabase/AI services. Local mode downloads the model and processes messages on your device after loading. Cloud mode requires an internet connection and a signed-in account.
