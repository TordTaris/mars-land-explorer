Install LOCAL MARS

Install the web app on your device for an app-like experience and access to previously cached pages.

  1. Open this site in Chrome on Android.
  2. Tap the browser menu (⋮).
  3. Select Install app or Add to Home screen.
  4. Confirm. LOCAL MARS will appear on your home screen.

On iPhone/iPad: open in Safari, tap Share, then choose “Add to Home Screen”.

LOCAL MARS is a Progressive Web App (PWA), not a Play Store APK. Installation availability depends on browser and device support.
