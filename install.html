OFFICIAL APP INSTALLATION

Take LOCAL MARS with you.

Install the LOCAL MARS web app on your device for a full-screen experience and access to previously cached pages. No app-store account is required.

Launch Web App ↗
🤖

Android

  1. Open this page in Chrome.
  2. Tap Install LOCAL MARS. If unavailable, open the ⋮ menu.
  3. Choose Install app or Add to Home screen.
  4. Confirm. Find LOCAL MARS on your home screen.
🍎

iPhone & iPad

  1. Open this page in Safari.
  2. Tap the Share button.
  3. Choose Add to Home Screen.
  4. Tap Add to finish installation.
💻

Windows, Mac & Chromebook

  1. Open this page in Chrome or Edge.
  2. Use the install icon in the address bar, or open the browser menu.
  3. Select Install LOCAL MARS and confirm.
About this download: LOCAL MARS is currently distributed as a Progressive Web App (PWA) through this official website. This page does not provide a native Android APK, iOS IPA, or Play Store/App Store listing. Installation options depend on your device and browser. Some features require an internet connection; offline access is limited to pages and resources already cached on your device.
