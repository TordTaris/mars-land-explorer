PROJECT PARAMETERS

A’ARU 1.1 · Initial design brief

The first release is a navigable LOCAL MARS project page and systems concept. Dimensions, population capacity, rotation rate, radiation shielding and power budgets remain to be engineered and validated before they can be treated as specifications.

Next engineering work: define ring radius and rpm, estimate floor area, calculate shielding mass, model life-support closure rates, and size the power/storage system.
